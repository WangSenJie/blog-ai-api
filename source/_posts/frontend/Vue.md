# `Vue` 简介

## `Vue` 是什么

`Vue` 是一个用来构建用户界面的 `JavaScript` 框架.

如果前面学的 `HTML`、`CSS` 和 `JavaScript` 是前端开发的基础三件套, 那么 `Vue` 可以理解成: 它是在这三件套之上, 提供了一套更高效的组织方式.

你可以先粗暴地把它理解成:

- `HTML` 用来写页面结构
- `CSS` 用来写页面样式
- `JavaScript` 用来写交互逻辑
- `Vue` 用来把这些内容更清楚地组织起来

所以 `Vue` 不是替代前端三件套, 而是建立在它们之上的一套开发方式.

## 为什么要用 `Vue`

当页面非常简单时, 只用原生 `HTML`、`CSS` 和 `JavaScript` 就够了.

但当页面越来越复杂时, 代码往往会出现这些问题:

- 页面结构越来越大
- 交互逻辑越来越多
- 手动操作 `DOM` 很繁琐
- 同样的页面块容易重复写

这时候 `Vue` 的价值就出来了.

它主要帮你解决这些问题:

- 用组件拆分页面
- 用数据驱动页面更新
- 更方便地处理事件和表单
- 让代码更容易维护

你可以把它理解成:  
页面复杂之后, `Vue` 能让前端代码没那么乱.

## 什么是组件

组件是 `Vue` 里非常重要的概念.

你可以把组件理解成: 页面中的一个独立小模块.

比如一个页面可以拆成:

- 顶部导航栏
- 侧边栏
- 文章卡片
- 评论区
- 登录框

这些都可以做成组件.

组件的好处是:

- 每一块功能更独立
- 可以重复使用
- 页面结构更清楚
- 后续修改时影响范围更小

例如一个按钮组件、一个卡片组件, 可以在多个页面里重复使用, 不需要每次都从头写一遍.

所以 `Vue` 的一个核心思路就是:  
把大页面拆成很多小组件.

## 什么是数据驱动视图

这是 `Vue` 最核心的思想之一.

所谓“数据驱动视图”, 可以简单理解成:

- 数据变了
- 页面会自动跟着变

在原生 `JavaScript` 里, 你可能需要手动:

- 选中元素
- 修改 `textContent`
- 处理页面更新

而在 `Vue` 里, 通常你只需要修改数据, 页面会自动重新渲染.

例如:

```vue
<template>
  <p>{{ message }}</p>
  <button @click="changeMessage">点我</button>
</template>

<script setup>
import { ref } from 'vue'

const message = ref('Hello Vue')

function changeMessage() {
  message.value = '你点击了按钮'
}
</script>
```

这里最重要的不是语法细节, 而是理解这个过程:

- `message` 是数据
- 页面显示 `message`
- 按钮点击后修改 `message`
- 页面自动更新

## 常见模板语法

`Vue` 模板语法就是在页面里把数据和界面连起来的写法.

最常见的有下面几种.

### 插值表达式

用 `{{ }}` 把数据直接显示到页面上:

```vue
<template>
  <p>{{ message }}</p>
</template>
```

如果 `message = 'Hello Vue'`, 页面上就会显示 `Hello Vue`.

### 绑定属性

用 `v-bind` 或简写 `:` 给标签属性绑定数据:

```vue
<template>
  <img :src="imageUrl" :alt="title" />
</template>
```

表示图片地址和说明文字不是写死的, 而是来自数据.

### 绑定事件

用 `v-on` 或简写 `@` 监听事件:

```vue
<template>
  <button @click="handleClick">点我</button>
</template>
```

表示点击按钮时执行 `handleClick`.

如果你只想先看懂大多数简单 `Vue` 代码, 先掌握这三个语法就够用了:

- `{{ }}`
- `:`
- `@`

## 常见指令

`Vue` 提供了一些很常用的指令, 用来控制页面渲染和交互.

### `v-if`

根据条件决定元素是否显示:

```vue
<template>
  <p v-if="isLogin">欢迎回来</p>
</template>
```

如果 `isLogin` 为真, 就显示这段内容.

### `v-for`

用来渲染列表:

```vue
<template>
  <li v-for="item in list" :key="item.id">
    {{ item.name }}
  </li>
</template>
```

表示把 `list` 里的每一项渲染出来.

### `v-model`

用来做表单双向绑定:

```vue
<template>
  <input v-model="username" />
</template>
```

它的作用是:

- 输入框内容变了, 数据会变
- 数据变了, 输入框内容也会变
