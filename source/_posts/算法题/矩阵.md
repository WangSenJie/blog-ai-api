# 矩阵

## (73) 矩阵置零
给定一个 `m x n` 的矩阵, 如果一个元素为 `0`, 则将其所在行和列的所有元素都设为 `0`. 请使用原地算法.

![矩阵置零](矩阵/mat1.jpg)

```
示例 1：


输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]
```

> 做两个循环, 第一次个循环处理行, 并记录零元素所在列; 第二个循环处理列.

```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        col_index = []
        for i, row in enumerate(matrix):
            f = 0
            for j, num in enumerate(row):
                if num == 0:
                    col_index.append(j)
                    f = 1
            if f == 1:   
                matrix[i] = [0] * len(row)
                
        for j in set(col_index):
            for i in range(len(matrix)):
                matrix[i][j] = 0
```

## (54) 螺旋矩阵
给你一个 `m` 行 `n` 列的矩阵 `matrix`, 请按照顺时针螺旋顺序, 返回矩阵中的所有元素.

![螺旋矩阵](矩阵/spiral1.jpg)

```
示例 1：

输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[1,2,3,6,9,8,7,4,5]
```

> 每次取出矩阵的第一行, 对余下矩阵进行转置和倒序处理 `list(zip(*matrix))[::-1]`

```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        res = []
        while matrix:
            res += matrix.pop(0)
            matrix = list(zip(*matrix))[::-1]
        return res
```

## $\star$(48) 旋转图像
给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像. 请你将图像顺时针旋转 `90` 度.

你必须在原地旋转图像, 这意味着你需要直接修改输入的二维矩阵. 请不要使用另一个矩阵来旋转图像.

![螺旋矩阵](矩阵/mat2.jpg)

```
示例 1：

输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```
> 先确定要旋转几圈, 不难看出要旋转 `n//2` 圈, 采取从外到里一圈一圈旋转. 对于第 `i` 圈, 取 `i ~ n-i-1` 位置元素为起始变换位置进行旋转操作

```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)
        for i in range(n//2):
            for j in range(i, n-i-1):
                tmp = matrix[i][j]
                matrix[i][j] = matrix[n-j-1][i]
                matrix[n-j-1][i] = matrix[n-i-1][n-j-1]
                matrix[n-i-1][n-j-1] = matrix[j][n-i-1]
                matrix[j][n-i-1] = tmp
```

## (240) 搜索二维矩阵II

编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target`. 该矩阵具有以下特性:
- 每行的元素从左到右升序排列.
- 每列的元素从上到下升序排列.

![搜索矩阵](矩阵/searchgrid2.jpg)
```
示例 1：
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
输出：true
```
> 从矩阵的右上角开始, 若小于 `target`, 则向下移动; 反之向左移动.

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m = len(matrix); n = len(matrix[0])
        r, c = 0, n-1
        while r <= m-1 and c >= 0:
            if matrix[r][c] > target:
                c -= 1
            elif matrix[r][c] < target:
                r += 1
            else:
                return True
        return False
```
