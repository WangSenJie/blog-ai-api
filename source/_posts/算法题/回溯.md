## $\star$ (46) 全排列
给定一个不含重复数字的数组 `nums`, 返回其所有可能的全排列

### 思路
事实上这是一个树结构, 以 `[1,2,3]` 为例, 即构造
```
    1        2       3
   / \      / \     / \
  2   3    1   3   1   2
  |   |    |   |   |   |
  3   2    3   1   2   1
```
- 先固定 `1`
  - 再固定 `2`, 最后固定 `3`, 得 `[1,2,3]`, 还原成 `[1,2,3]`
  - 交换 `2` 和 `3`, 即固定 `3`, 最后固定 `2`, 得 `[1,3,2]`, 还原成 `[1,2,3]`
  - 还原成 `[1,2,3]`
- 交换 `1` 和 `2`, 即固定 `2`
  - 固定 `1`, 最后固定 `3`, 得 `[2,1,3]`, 还原成 `[2,1,3]`
  - 交换 `1` 和 `3`, 即固定 `3`, 最后固定 `1`, 得 `[2,3,1]`, 还原成 `[2,1,3]`
  - 还原成 `[1,2,3]`
- 交换 `1` 和 `3`, 即固定 `3`
  - 固定 `2`, 最后固定 `1`, 得 `[3,2,1]`, 还原成 `[3,2,1]`
  - 交换 `1` 和 `2`, 即固定 `1`, 最后固定 `2`, 得 `[3,1,2]`, 还原成 `[3,2,1]`
  - 还原成 `[1,2,3]`
```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        result = []
        def dfs(index):
            if index == len(nums)-1:
                result.append(nums[:])
                return
            
            for i in range(index, len(nums)):
                nums[i], nums[index] = nums[index], nums[i]
                dfs(index+1)
                nums[i], nums[index] = nums[index], nums[i]
        
        dfs(0)
        return result
```

## $\star$ (78) 子集

给你一个整数数组 `nums`, 数组中的元素互不相同. 返回该数组所有可能的子集(幂集).

解集不能包含重复的子集. 你可以按任意顺序返回解集.

```
示例 1：

输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

示例 2：

输入：nums = [0]
输出：[[],[0]]
```
### 思路
采用回溯算法:
- 构造函数 `helper(i, tmp)`, 代表此时将第 `i` 个元素加入到 `tmp` 列表中, 其中 `i` $\in$ `[0, len(nums)]`, `i=0` 代表不将元素加入 `tmp` 中.
- 函数 `helper` 先将当前 `tmp` 存入返回参数 `res` 中, 然后从第 `i` 个元素开始向后遍历 `nums` 数组, 执行 `helper` 过程.
```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        result = []
        def helper(i, tmp):
            result.append(tmp)
            for j in range(i, len(nums)):
                helper(j+1, tmp+[nums[j]])
        
        helper(0, [])
        return result
```

## (17) 电话号码的字母组合

给定一个仅包含数字 `2-9` 的字符串, 返回所有它能表示的字母组合. 答案可以按任意顺序返回.

![电话号码](https://pic.leetcode.cn/1752723054-mfIHZs-image.png)

```
示例 1：

输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

```python
class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        def cup(l1, l2):
            # value_n = dig_dic[n]
            # value_m = dig_dic[m]
            tmp = []
            for i in l1:
                for j in l2:
                    tmp.append(i+j)
            return tmp
        
        dig_dic = {
            '2': ['a', 'b', 'c'],
            '3': ['d', 'e', 'f'],
            '4': ['g', 'h', 'i'],
            '5': ['j', 'k', 'l'],
            '6': ['m', 'n', 'o'],
            '7': ['p', 'q', 'r', 's'],
            '8': ['t', 'u', 'v'],
            '9': ['w', 'x', 'y', 'z']
        }

        if len(digits) == 1:
            return dig_dic[digits]

        res = dig_dic[digits[0]]
        for i in range(1, len(digits)):
            res = cup(res, dig_dic[digits[i]])
        
        return res
```

## (39) 组合总和
```
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。
```
### 思路
采用回溯算法:
- 先找 `2` 开头的组合, 那么 `target=7-2=5`, `tmp=[2]`
  - 同样先找 `2` 开头的组合, 那么 `target=5-2=3`, `tmp=[2,2]`
    - 同样先找 `2` 开头的组合, 那么 `target=3-2=1`, `tmp=[2,2,2]`
      - 还是先找 `2` 开头的组合, 那么 `target=1-2=-1<0`, 不满足题意, 退出.
      - 再找 `3` 开头的组合, 那么 `target=1-3=-2<0`, 不满足题意, 退出.
      - 再找 `6` 开头的组合, 那么 `target=1-6=-5<0`, 不满足题意, 退出.
      - 再找 `7` 开头的组合, 那么 `target=1-7=-6<0`, 不满足题意, 退出.
      - `tmp` 推出 `2`, 即 `tmp=[2,2]`.
    - 再找 `3` 开头的组合, 那么 `target=3-3=0`, `tmp=[2,2,3]`, 满足要求, 存储 `tmp`. `tmp` 推出 `3`, 即 `tmp=[2,2]`, 退出
    - 再找 `6` 开头的组合, 那么 `target=3-6=-3<0`, 不满足题意, 退出.
    - 最后找 `7` 开头的组合, 那么 `target=3-7=-4<0`, 不满足题意, 退出.
    - `tmp` 推出 `2`, 即 `tmp=[2]`.
  - 再找 `3` 开头的组合, 那么 `target=5-3=2`, `tmp=[2,3]`
    - 再找 `3` 开头的组合, 那么 `target=2-3=-1<0`, 不满意题意, 退出.
    - 再找 `6` 开头的组合, 那么 `target=2-6=-4<0`, 不满意题意, 退出.
    - 再找 `7` 开头的组合, 那么 `target=2-7=-5<0`, 不满意题意, 退出.
    - `tmp` 推出 `3`, 即 `tmp=[2]`.
  - 再找 `6` 开头的组合, 那么 `target=5-6=-1<0`, 不满足题意, 退出.
  - 再找 `7` 开头的组合, 那么 `target=5-7=-2<0`, 不满足题意, 退出.
- ...

```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        result = []
        def helper(tmp, i, target):
            if candidates[i] > target:
                return
            
            tmp.append(candidates[i])
            if candidates[i] == target:
                result.append(tmp)
                tmp.pop()
                return
            
            for j in range(len(candidates)):
                helper(tmp, j, target-candidates[i])
            
            tmp.pop()
        
        for i in range(len(candidates)):
            helper([], i, target)

        return result
```

## 括号生成
数字 `n` 代表生成括号的对数, 请你设计一个函数, 用于能够生成所有可能的并且有效的括号组合.

示例 1：
```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

### 思路
采用回溯算法:
- 构造一个函数 `helper` 其参数为 `(tmp, l, r)`, 分别是当前括号组合、左括号数量、右括号数量. 显然这个组合有效当且仅当 `len(tmp) = 2*l = 2*r = 2*n`.
- 定义停止条件: 若 `len(tmp) == 2*n`, 则记录该组合, 退出.
- 初始化 `tmp=[], l=0, r=0`
- `len(tmp)=0<2*n`
  - `l=0<n`
    - `tmp=['(']`
      - `len(tmp)=1<2*n`
        - `l=1<n`
          - `tmp=['(', '(']`
            - `len(tmp)=2<2*n`
              - `l=2=n>r=0`
                - `tmp=['(', '(', ')']`
                  - `len(tmp)=3<2*n`
                    - `l=2=n>r=1`
                      - `tmp=['(', '(', ')', ')']`
                        - `len(tmp)=4=2*n`
                          - 记录
                      - 推出 `)`, 即 `tmp = ['(', '(', ')]'`
                - 推出 `)`, 即 `tmp=['(', '(']`
          - 推出 `(`, 即 `tmp=['(']`
            - `l=1>r=0`
              - `tmp=['(', ')']`
                - ...

```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        result = []
        def helper(l, r, tmp):
            if len(tmp) == 2*n:
                result.append(''.join(tmp))
            
            if l < n:
                tmp.append('(')
                helper(l+1, r, tmp)
                tmp.pop()
            if r < l:
                tmp.append(')')
                helper(l, r+1, tmp)
                tmp.pop()
        
        helper(0, 0, [])

        return result
```

## 79. 单词搜索
给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word`. 如果 `word` 存在于网格中, 返回 `true`; 否则, 返回 `false`.

单词必须按照字母顺序, 通过相邻的单元格内的字母构成, 其中"相邻"单元格是那些水平相邻或垂直相邻的单元格. 同一个单元格内的字母不允许被重复使用.
 
![单词搜索](https://assets.leetcode.com/uploads/2020/11/04/word2.jpg)
```
示例 1：

输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"
输出：true
```

### 思路
回溯

```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        def helper(r, c, index):
            if index == len(word):
                return True
            
            if not 0 <= r <= len(board)-1 or not 0 <= c <= len(board[0])-1 or board[r][c] != word[index]:
                return False
            
            tmp, board[r][c] = board[r][c], '#'

            f = (
                helper(r-1, c, index+1) or
                helper(r+1, c, index+1) or
                helper(r, c-1, index+1) or
                helper(r, c+1, index+1)
            )

            board[r][c] = tmp

            return f

        for r in range(len(board)):
            for c in range(len(board[0])):
                if helper(r, c, 0):
                    return True
        
        return False
```

## 131. 分割回文串
给你一个字符串 `s`, 请你将 `s` 分割成一些子串, 使每个子串都是回文串. 返回 `s` 所有可能的分割方案.

```
示例 1：

输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]

示例 2：

输入：s = "a"
输出：[["a"]]
```

### 思路
用回溯方法


```python
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        def is_palindrome(s):
            '''
                判断是否是回文串
            '''
            return s == s[::-1]
        
        def helper(i, tmp):
            if i == len(s):
                # 本次分割结束
                result.append(tmp[:])
                return
            for j in range(i+1, len(s)+1):
                substr = s[i:j]

                if is_palindrome(substr):
                    tmp.append(substr)
                    helper(j, tmp)
                    tmp.pop()
                
        result = []
        helper(0, [])

        return result
```
