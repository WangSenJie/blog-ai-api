# 双指针
## (283) 移动零

给定一个数组 `nums`, 编写一个函数将所有 `0` 移动到数组的末尾, 同时保持非零元素的相对顺序.

请注意, 必须在不复制数组的情况下原地对数组进行操作.

```
示例 1:

输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]
```

> 用一个 `index_zero` 指向零元素的 `index`, 初始化 `index_zero = -1`, 用另一个指针 `i` 遍历 `nums` 数组
> - 如果 `i` 位置是 `0`, 且 `index_zero = -1`, 则赋值 `index_zero <- i`
> - 如果 `i` 位置是 `0`, 且 `index_zero != -1`, 则说明 `index_zero - i` 之间都是零元素, 此时继续向右移动指针 `i` 去找非零元素
> - 如果 `i` 位置非 `0`, 且 `index_zero = -1`, 说明指针 `i` 还没遇到零元素, 因此只需继续向右移动指针 `i`
> - 如果 `i` 位置非 `0`, 且 `index_zero != -1`, 说明指针 `index_zero - i-1` 之间都是零元素, 此时交换 `index_zero` 和 `i` 位置的元素, 将零元素往后移, 随后更新 `index_zero <- index_zero + 1` (此时 `index_zero + 1` 一定是零元素)

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        index_zero = -1
        for i in range(len(nums)):
            if nums[i] == 0 and index_zero == -1:
                index_zero = i
            elif nums[i] != 0 and index_zero != -1:
                nums[index_zero], nums[i] = nums[i], nums[index_zero]
                index_zero += 1
```

## (11) 盛最多水的容器
给定一个长度为 `n` 的整数数组 `height`. 有 `n` 条垂线, 第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`.

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水.

返回容器可以储存的最大水量.

说明: 你不能倾斜容器.

![question11](双指针/question_11.jpg)

```
示例 1：

输入：[1,8,6,2,5,4,8,3,7]
输出：49 
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。
```

> 用 **双指针** 思路, 其中 `left` 指针指向容器的左侧, `right` 指向容器的右侧.
> - 初始化 `left = 0, right = n-1, V_max = 0`
> - 在 `left < right` 的前提下执行循环
>   - 每次循环计算当前容器的体积 `V = min(height[left], height[right]) * (right-left)`, 更新 `V_max = max(V_max, V)`
>   - 如果 `height[left] < height[right]`, 则将 `left` 向右移动; 反之, 将 `right` 向左移动.

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        n = len(height)
        left = 0; right = n-1
        v_max = 0
        while left < right:
            v = min(height[left], height[right]) * (right-left)
            v_max = max(v_max, v)
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return v_max
```

## $\star$(15) 三数之和

给你一个整数数组 `nums`, 判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j、i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0`. 请你返回所有和为 `0` 且不重复的三元组.

注意: 答案中不可以包含重复的三元组.

```
示例 1：

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
```
注意，输出的顺序和三元组的顺序并不重要。

> 采用 **双指针** 思想
> - 如果 `len(nums) < 3`, 则一定找不到满足条件的三数组合, 直接返回空
> - 对数组 `nums` 进行排序 (升序)
> - 遍历 `nums` 中的所有数 `(i, num)`, `i` 为 `num` 的下标
>   - 如果 `num > 0`, 则说明后续所有数都为正数, 那么一定找不到三数之和为 `0` 的组合, 直接推出循环;
>   - 如果 `num` 和前一轮循环的数一样, 则跳过此轮循环
>   - 如果 `num <= 0`, 则构造指针 `left = i+1, right = len(nums) - 1`
>       - 如果 `num + nums[left] + nums[right] < 0`, 则需要增大组合数的和, 只需执行 `left += 1`; 反之, 则执行 `right -= 1`
>       - 随后, 要注意更新 `left` 和 `right`. 将 `left` 指针不断往右移, 直至指向第一个不同的点; 将 `right` 指针不断往左移, 直至指向第一个不同的点

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
         n = len(nums)
        if n < 3:
            return
        res = []
        nums.sort()
        for i, num in enumerate(nums):
            if num > 0:
                break
            if i >= 1 and num == nums[i-1]:
                continue
            left = i+1; right = n-1
            while left < right:
                if num+nums[left]+nums[right] < 0:
                    left += 1
                elif num+nums[left]+nums[right] > 0:
                    right -= 1
                else:
                    res.append([num, nums[left], nums[right]])
                    while left<right and nums[left] == nums[left+1]:
                        left += 1
                    while left<right and nums[right] == nums[right-1]:
                        right -= 1
                    left += 1
                    right -= 1
        return res
```

## (42) 接雨水
给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图, 计算按此排列的柱子, 下雨之后能接多少雨水.

![接雨水](双指针/rainwatertrap.png)

```
示例 1：

输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 
```

> 采用双指针 `left` 和 `right`, 其中 `left` 从最左边的柱子开始向右移动, `right` 从最右边的柱子开始向左移动
> - 初始化接的雨水量 `result = 0`, `left_max = 0, right_max = 0`, 其中 `left_max` 记录左边柱子的最大高度, `right_max` 记录右边柱子的最大高度
> - 在 `left < right` 的前提下进行循环
>   - 每次更新 `left_max = max(left_max, height[left]), right_max = max(right_max, height[right])`
>   - 如果 `height[left] < height[right]`, 则记录 `result <- result + (left_max-height[left])`, 同时向右移动 `left <- left + 1`; 反之, 则记录 `result <- result + (right_max-height[right])`, 同时向右移动 `right <- right - 1`

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        left = 0; right = n-1
        left_max = 0; right_max = 0
        res = 0
        while left < right:
            left_max = max(left_max, height[left])
            right_max = max(right_max, height[right])
            if height[left] < height[right]:
                res += left_max-height[left]
                left += 1
            else:
                res += right_max-height[right]
                right -= 1
        return res              
```
